Darrell Perez Guerrero C4I350


## Descripción
Libro interactivo educativo desarrollado en Java (Maven) bajo la arquitectura Modelo-Vista-Controlador (MVC), enfocado en la exploración del método científico a través del estudio de críptidos y leyendas biológicas.

## Estructura del Proyecto
* `cr.ac.ucr.criptobitacora.modelo`: Jerarquía de clases (`Criptido`, `CriptidoTerrestre`, `CriptidoAcuatico`), interfaces (`Investigable`) y colecciones.
* `cr.ac.ucr.criptobitacora.vista`: Componentes de interfaz gráfica en Java Swing.
* `cr.ac.ucr.criptobitacora.controlador`: Coordinación entre vistas y lógica.
* `cr.ac.ucr.criptobitacora.main`: Punto de entrada de la aplicación.
